# Interpretation boundaries

The toolkit enforces the following distinctions:

- A variable being present does not mean it has usable coverage.
- Usable coding does not mean two items measure the same construct.
- Matching labels do not prove matching wording, universe, routing, or mode.
- Normalizing missing codes does not make missingness mechanisms equivalent.
- Reversing or shifting a scale aligns coding direction/endpoints, not psychometric properties.
- A canonical category may be coarser than every source and should retain a comparability note.
- A harmonized file is not, by itself, a justified pooled analytic dataset.

Blocked mappings are part of the scientific output. They document where the available evidence is insufficient for transformation.
